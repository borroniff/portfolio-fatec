## 🚀 Competências Técnicas

### 💻 Desenvolvimento de Software e Gestão de Banco de Dados
* **Back-end:** Arquitetura e construção de APIs RESTful utilizando **Java** e o framework **Spring Boot**.
* **Front-end:** Desenvolvimento de interfaces de usuário dinâmicas e responsivas com **React** e **Node.js**.
* **Banco de Dados:** Aplicação de persistência de dados utilizando Sistemas Gerenciadores de Banco de Dados (SGBD) **Relacional** como MySQL e **Não relacional** como MongoDB.

### ⚙️ Cultura DevOps e Infraestrutura
* **Controle de Versão:** Gestão de código e ramificações baseadas em metodologias sólidas como *Git Workflow*.
* **Containerização & Deploy:** Criação e manutenção de ambientes isolados, pipelines de build, testes integrados e deploy automatizado utilizando **Docker** e **Docker Compose**.

### 🎯 Gestão Ágil de Projetos
* **Liderança de Produto:** Atuação direta como *Product Owner* (PO), garantindo o alinhamento entre as necessidades do negócio/cliente e a entrega técnica.
* **Mapeamento de Requisitos:** Concepção de *Product Backlog* através da metodologia *Product Backlog Building (PBB)*, com detalhamento técnico de *User Stories* em *Tasks* acionáveis.
* **Governança de Sprints:** Planejamento, organização e acompanhamento de métricas de desenvolvimento utilizando **Jira** e **Trello**.
